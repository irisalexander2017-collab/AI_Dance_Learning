# Lessons Learned

Add verified lessons after development or testing reveals them.

- 对于需要观察任意身体局部的视频学习工具，自由缩放和拖动比预设手部/脚部按钮更灵活，也能减少功能复杂度。
- 先完成手动可校准的八拍学习逻辑，再加入自动音乐分析，可以把交互逻辑问题和算法识别问题分开测试，降低调试难度。
- 视频学习工具的核心是保持视频持续可见。低频设置应折叠，高频操作应固定，并根据普通页面和全屏场景采用不同控制布局。

## 2026-10-11 — 手机练舞与网页验收

- 视频缩放与底栏必须是独立区域；设置展开时缩短视频可用区域，而不是遮盖正在定位的画面。
- 构建通过和DOM存在不证明按钮可用。交付前用真实浏览器跑中英文、小屏、横屏、展开/收起和录制回归，并保存具体证据。
- 自动估算和用户确认必须分开保存；异步分析不能覆盖手动校准，旧循环计时器也不能在改节拍后恢复旧范围。
- 录像既要检查下载文件有音轨，也要检查音轨确有声音；测试摄像头和手机尺寸模拟不能写成真机兼容性已验证。

## 2026-10-11 — 自动BPM验收

- “算法存在、显示了数字”不等于识别准确。用已知速度的音频与有独立参考的真实音乐核对，记录数值和误差，不把单一样本写成准确率。
- 非负起音曲线有背景基线，纯噪声也可能得到很高自相关。测试必须包含噪声、持续单音和变化速度，而不只测规则鼓点。
- 自动结果不能覆盖正在输入的数值；临时草稿与已确认设置分开保存。刷新测试要覆盖未点击确认的情况。
- 取消与超时必须覆盖读取、解码和计算全流程；旧默认值不能作为识别失败后的成功结果。
- 旧设置重分析时，同速度应保留用户自定义边界，不能因迁移标记而清空。

## 2026-10-11 — 用户音乐样本误判

- 规则鼓点与一个真实样本通过，仍不足以证明不同音乐都准确。用户报告必须用她指定的原文件在真实网页复现，不能拿已有成功样本代替。
- 低音重复周期不一定是主拍。归一化后各频段证据需要平衡，候选近同分且非正常二倍关系时应拒绝确定结果。
- 统计分片一致性时，不能删除失败的有声音片段后，只剩一个成功片段就宣称“多片段确认”。静音片头与有声音但无法识别的片段要区别处理。
- 失败媒体用本机路径参数加入回归，不把用户原视频提交到Git或上传外部分析服务。

## 2026-10-11 — 连续设置流程

- 保存过的值不等于本次操作已经确认。多步设置应独立记录本次步骤，网页测试同时覆盖首次设置、旧设置重进和刷新恢复。
- 保存恢复测试应先断言实际保存值，再刷新；不使用固定等待或反复重试掩盖偶发失败。构建、源码检查和新用例通过之后，仍需完整网页回归。
